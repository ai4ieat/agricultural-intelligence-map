# Agricultural Intelligence Map

Map Explorer รุ่น 0.2.0 ตาม Design 1: ตัวกรองซ้าย แผนที่กลาง รายละเอียดขวา และแผงเลื่อนบนมือถือ ใช้ snapshot ข้อมูลจริงจาก Google Sheets 4 ไฟล์ นำเข้า 9 ตุลาคม 2026

## เปิดเว็บ

ต้องมี Node.js 22 ขึ้นไป ไม่ต้องติดตั้ง npm packages

```powershell
npm start
```

เปิด http://127.0.0.1:8010/ หรือใช้ `node scripts/serve.mjs` โดยตรง พอร์ตเริ่มต้น 8010; เปลี่ยนได้ด้วยตัวแปร `PORT` เซิร์ฟเวอร์รับเฉพาะ localhost

## สิ่งที่ใช้งานได้

- สีผลผลิต/พื้นที่เกษตร 6 พืช 364 คู่พืช–จังหวัด พร้อมปีและที่มา
- ค้นทะเบียนโรงงาน กนอ. 8,604 รายการสถานะปกติ กรองภาค จังหวัด อำเภอ หมวดอุตสาหกรรมและนิคม พร้อมดาวน์โหลด CSV
- ขอบเขตและจุดนิคมจาก IEAT Estate Atlas คลิกดูรายละเอียดและดาวน์โหลด GeoJSON
- งานวิจัย 36 งาน เชื่อมพืช–อุตสาหกรรม พร้อม DOI และสถานะรอตรวจรับ
- เปรียบเทียบข้อมูลระหว่าง 2 จังหวัด

จุดสีม่วงแทนนิคม/สำนักงาน **ไม่ใช่พิกัดรายโรงงาน** จำนวนทะเบียนเป็นจำนวนรายการต้นทาง อาจซ้ำ และครอบคลุมเฉพาะชุด กนอ. ไม่ใช่ทุกโรงงานของประเทศ

## อัปเดตข้อมูล

ส่งออก Google Sheets เป็น XLSX ลงโฟลเดอร์ชั่วคราว ตั้งชื่อ `factories.xlsx`, `agriculture.xlsx`, `reference.xlsx`, `research.xlsx` แล้วรัน Python ที่มี openpyxl:

```powershell
python scripts/import-sheets.py C:/path/to/exports
npm run validate
npm test
```

เว็บอ่าน `public/data/explorer-data.json` จากเว็บเดียวกัน ไม่อ่าน Google Sheets โดยตรง ไม่ใช้ฐานข้อมูลหรือ API ระบบน้ำเดิม และยังไม่เชื่อม n8n / AI / RAG

Basemap และฟอนต์แผนที่โหลดจาก OpenFreeMap จึงต้องใช้อินเทอร์เน็ต ส่วนข้อมูลธุรกิจอยู่ใน JSON ภายในโปรเจกต์

ข้อมูลและวิธีอัปเดต snapshot: [DATA.md](DATA.md) · เครดิตและใบอนุญาต: [ATTRIBUTION.md](ATTRIBUTION.md)

## หน้าคลังวิจัยแยก

เปิด http://127.0.0.1:8010/research.html หรือกดเมนู “งานวิจัย” ด้านบน ดูทั้งหมด 36 งาน ค้นข้อความ วัตถุดิบ และ Output พร้อมตัวกรองพืช อุตสาหกรรม ประเภทการศึกษา ระดับการพัฒนา ปี สถานะ องค์กร และการเชื่อมรหัสพืช เงื่อนไขถูกเก็บใน URL รองรับทั้งสองธีม


## เผยแพร่แบบ Static

GitHub Actions ตรวจข้อมูลและ tests ก่อนเผยแพร่เฉพาะ `public/` ไปยัง GitHub Pages ทุกครั้งที่ push สู่ `main` ไม่ต้องมี server/database ใน production ตั้งค่า Repository → Settings → Pages → Source เป็น GitHub Actions

ไฟล์ส่งออกจากชีต บันทึกทำงาน ภาพตรวจงาน และข้อมูลการเข้าถึงบริการไม่รวมใน repository
